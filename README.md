# Fallen Grace

Survivors-like в тёмном фэнтези-стиле: падший ангел против орд демонов и ангелов-охотников.
Платформы: ПК (Steam) и мобильные (Android/iOS).

**Движок:** Unity 6 (6000.2.x), URP, Input System.

## Как открыть
1. Unity Hub → Add → выбрать эту папку.
2. Открыть сцену `Assets/Scenes/Game`.
3. Нажать Play. Управление: WASD / геймпад / сенсорный джойстик, 1–3 — выбор улучшения, Esc — пауза.

Меню **Fallen Grace** в редакторе: собрать сцену и префабы, пересобрать префабы.

## Структура
- `Assets/Scripts` — код (Core, Player, Enemies, Combat, Progression, UI, Editor)
- `Assets/Game/Prefabs` — герой, враги, снаряд, осколок души
- `Assets/Game/Enemies` — настройки врагов (здоровье, скорость, урон)
- `Assets/Scenes/Game` — основная сцена
